这个只读工具返回当前项目的应用运行环境规划、初始化状态、依赖服务和应用镜像，用于判断某项操作是否依赖项目级运行拓扑。

使用规则：
1. 只有任务确实依赖项目应用服务、依赖容器、端口、镜像或项目级环境变量时，才调用 `get_project_runtime_environment_info`。同一次运行成功读取一次后复用已有结果；仅当本轮执行了环境重新初始化、镜像重建或其他可能改变环境状态的动作后再刷新。
2. 返回内容是精简后的权威环境视图，包括初始化状态、识别到的技术栈、应用组件、依赖服务、端口、镜像和非敏感环境变量。密钥值会隐藏，生成配置文件正文、Dockerfile 和扫描明细不会返回。
3. 启动应用或连接依赖服务时，以这个环境视图中的当前状态和连接信息为准；需要文件正文时读取当前项目工作区中的真实文件，不要反复调用本工具代替代码读取。
4. 这个工具不修改项目、不生成镜像，也不更新环境。
5. 如果环境状态不是 `ready`，不得假设项目应用、依赖服务或应用访问目标已经可运行；需要这些能力时必须明确说明缺失或失败信息。
6. 项目应用环境状态不等于当前项目文件和终端工具的可用状态。本轮已经暴露的文件或终端工具可以直接使用，不能仅因应用环境为 `pending` 而阻塞通用代码维护、文件读写、版本检查和命令验证。
7. 只有明确依赖项目应用服务、依赖容器、项目环境变量或生成配置的操作，才要求项目应用环境为 `ready`。
