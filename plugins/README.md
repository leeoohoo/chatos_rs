# First-party plugins

The first-party ChatOS plugins are maintained in this repository so client protocol, permission, packaging, local application, and release changes can be reviewed together.

- `browser/`: Rust Browser CDP MCP, launcher package, skill, and Chrome bridge extension source.
- `computer-use/`: native macOS and Windows Computer Use MCP implementations.
- `document/`: TypeScript Office and PDF MCP with workspace and managed-artifact boundaries.
- `diagram-studio/`: TypeScript MCP plus a packaged local visual workbench for structured diagrams and PlantUML interoperability.

Plugins may provide MCP servers, skills, permission declarations, managed artifacts, and local application surfaces. Runtime data can be isolated by user and project according to the plugin manifest.

The root `make build-plugins` and `make test-plugins` targets cover Browser, Computer Use, and Document Tools. Diagram Studio uses its own npm workflow:

```bash
npm --prefix plugins/diagram-studio test
npm --prefix plugins/diagram-studio run pack:verify
```

Only source, tests, manifests, lockfiles, scripts, licenses, and reproducibility metadata are tracked. Build outputs, package archives, downloaded dependencies, and vendor executables are regenerated by each plugin's build scripts. Document plugin tests fetch and checksum the current platform's OfficeCLI runtime before exercising Office mutations.
