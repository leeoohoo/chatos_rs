# Web Design Studio v2 阶段 0 视觉评审

评审对象：`v3.0.1-legacy-current`

评审范围：12 类网站、10 个 CSS 视口、120 张设计预览截图。截图和机器报告生成在被 Git 忽略的 `.web-design-studio-baselines/v3.0.1-legacy-current/`，避免把大体积回归产物提交进插件安装包。

## 客观结果

- 120/120 张截图成功；
- 12 个 Brief 只有 1 种文档结构；
- 所有设计均为 1 个页面、8 个组件；
- 组件组成完全一致：1 个 Button、3 个 Card、1 个 Image、1 个 Section、2 个 Text；
- 8/10 个视口组在 12 类网站之间像素完全相同；
- 48/120 张截图存在横向溢出；
- 36 个 QHD、4K、8K 截图的设计表面不足视口宽度的一半。

## 人工视觉结论

### 视觉层级：6/16

旧模板具备基本首屏标题、说明和主按钮，但它不根据网站目标改变信息层级。电商、杂志、医疗、活动、地产和开发者文档都被表达成同一个 AI 产品落地页。

### 布局与节奏：4/16

桌面 1200px 下的基础间距尚可，但布局依赖固定坐标。页面只有一个首屏和三张卡片，没有完整网站所需的跨区节奏、内容密度变化与长页面结构。

### 连续响应式：1/16

导出的设计表面固定为 1200px。320、390、768 和 1024 视口直接裁切桌面布局，没有重排；4K 和 8K 则留下大面积无意义背景。现有离散设备数据没有转化为连续网页规则。

### 排版：5/12

字体选择和桌面字号基本可读，但窄屏标题、说明文字和按钮区域被裁切。排版没有根据内容类型、行长和设备宽度求解。

### 品牌与原创性：1/12

12 个完全不同的 Brief 使用相同颜色、相同文案、相同卡片和相同视觉方向。当前输出无法证明理解了品牌、行业或参考资料。

### 内容完整度：1/10

每种网站要求至少 4 个页面和 6 个关键分区，旧生成器只产生 1 个页面和 8 个通用组件。不存在商品、议程、文章、医生、课程、捐赠、户型或 API 文档等领域内容结构。

### 交互与状态：1/10

输出主要是静态首屏。没有能够支撑各类网站任务的导航、筛选、表单流程、弹层、状态反馈和跨页面原型。

### 可编辑与可追踪：3/8

节点有稳定 ID、revision 和基础父子关系，这是可保留能力；但节点语义过弱，AI 仍需理解大量绝对坐标，也无法查询“议程”“商品集合”或“医生列表”等不存在的语义区域。

## 当前总分

**22/100**

该分数不是 v2 的目标，也不是对某张截图的审美偏好，而是根据阶段 0 固定评分规则，对当前确定性生成路径的综合基线。

## 进入阶段 1 的约束

阶段 1 可以开始，但必须满足以下约束：

1. 不为旧 Schema 增加兼容字段；
2. v2 Scene Graph 使用独立模块和独立测试；
3. projectId 透传、revision 冲突、原子写入和真实第三方运行时继续作为冻结能力；
4. 阶段 1 只解决无损数据模型、层级、事务和保存恢复，不提前制作新工作台外观；
5. 阶段 2 完成后必须重新运行同一套 120 张截图，首先消除横向溢出和固定 1200px 画布；
6. 最终生产门槛不是“高于 22 分”，而是 12 类网站都通过独立视觉评审，且不能用同一个模板提高平均分。

## 阶段 0 验收结论

阶段 0 已建立可执行 Brief、视口矩阵、评分规则、冻结测试、隔离种子数据、轻量预览、120 张截图、机器失败报告和人工视觉评审。可以进入阶段 1：Schema v2 与 Scene Graph。
