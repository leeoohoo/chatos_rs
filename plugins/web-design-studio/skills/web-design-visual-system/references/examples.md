# Visual examples

## Positive

A developer tool site uses a dark neutral base, one electric accent, compact mono metadata, generous editorial headings, subtle grid texture, and consistent 8/16/24/40 spacing.

An architecture studio site uses oversized serif project titles, quiet sans-serif metadata, warm paper surfaces, asymmetric image crops, long horizontal rules, and generous transitions between dense project facts and open image-led sections. The choices express the studio's editorial character rather than a component-library default.

## Negative

Apply several unrelated gradients, glass cards, neon shadows, identical feature cards, and tiny body text because each effect or component is individually available. The result has no audience-specific visual concept.

## Focused revision

When the user asks to improve one section, preserve the established token system and neighboring geometry. Change only the targeted composition and any shared token explicitly needed by it.
