# Research, data, and operations scenarios

Split independent source families, hypotheses, competitors, or jurisdictions when parallel investigation improves coverage. Add a synthesis Task that distinguishes evidence, inference, uncertainty, and recommendation. Require source scope, freshness, comparison dimensions, citations, and explicit gaps.

For data work, common stages are inventory/quality -> cleaning/query preparation -> analysis -> independent validation -> presentation. Combine them for small tightly coupled datasets. Record identity, filters, units, definitions, formulas, assumptions, reproducible scripts/queries, and checks. Avoid multiple writers to the same workbook, table, or pipeline.

For migrations, releases, bulk changes, and incidents, distinguish planning, execution, verification, and rollback readiness. Use prerequisites for irreversible or externally visible steps. Preparation does not authorize deployment, publication, deletion, or messaging. Acceptance should include preconditions, checkpoints, observable success, recovery, and an audit trail.
