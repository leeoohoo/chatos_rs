# Agent 摘要等待与原运行恢复修复

## 故障证据

本地 Todo Executor 于 2026-11-11 18:07 启动，18:11 进入 `needs_review`，错误为 `active summary poll timed out after 120000 ms`。云端同一 Todo 的摘要任务 18:09:30 开始，18:13:51 成功结束，处理 9 条记录。摘要未失败，是客户端固定两分钟等待期限先结束了。

11 月 12 日用户多次点击继续，Swift 运行记录新增了执行入口事件，Rust Run 的版本、更新时间和失败结果却未变化：恢复入口仅查询已有 Host Run，没有发出恢复命令。

## 实现

- 共享 AI Runtime 持续等待云端摘要的实际状态，由服务端任务期限和租约回收决定结束。单次请求错误仍正常上报，调用者取消或失去租约仍中止等待。删除客户端摘要总等待期限，不通过延长期限掩盖任务状态。
- 明确的继续或重试操作恢复同一 Host Run、Turn 和 checkpoint，携带运行与会话版本进行原子状态校验。启动时对账不自动重试需要检查的运行，等待用户回答的运行也不被空回答恢复。
- 需要检查的 Host Run 映射为需要检查，不再混成普通暂停。恢复开始立即显示运行状态。
- 恢复事务同时重新打开 Turn，清理旧终止结果；再次中断或成功时更新同一可见结果，避免终止状态冲突及重复主键。Memory 中的中断诊断按 Run 版本单独保留。

## 回归验证

- 虚拟时钟下摘要持续五分钟后成功；失败、接口错误与取消均可结束等待。
- 真 SQLite 内存库完成两次中断及恢复，最终成功；保留 checkpoint，清除旧终止结果，重放恢复命令幂等，启用 Memory 投影验证诊断无冲突。
- Mac Host Stub 验证明确恢复发出恢复命令及正确版本，不创建重复 Turn；启动对账和等待用户回答不触发恢复。
- 群聊调度、取消和恢复现有测试一并回归。

## Mac 重启后的配置遗漏

安装后通过真实界面恢复原运行时，在线控制面同步完成，但团队执行器仍报未配置。代码核对发现：本地快照恢复工厂传入了 `localAgentTeamExecutor`，在线同步工厂遗漏这一参数，且参数有 nil 默认值，因此编译未发现遗漏。

两个入口已使用同一个工厂构造函数，并去掉构造参数的默认值。服务配置、Host 启动、在线控制面同步及群聊恢复测试一并通过。

## 旧运行恢复时的容量配置

原运行成功发出恢复命令后，Host 版本从 3 前进到 6、迭代从 1 前进到 2，但 Memory compose 返回 `model_capability_revision is not published`。只读核对发现：原运行引用旧模型快照中的 `model-capability-200k-v1`，控制面已同步配置中心当前发布的 `vendor-common-2026-11-12-v1`。删除旧容量配置时遗漏了已有运行的恢复链路。

容量属于配置中心当前发布的统一策略，不属于冻结的模型选择。Rust Host 在解析旧模型快照及缓存运行时后，使用已认证控制面同步的当前容量字段；模型、凭据及执行历史保持原运行设置。Swift Runtime 恢复时同样更新容量，并重新组合 Memory。无需恢复旧配置、增加容量默认值或修改用户数据库。

回归覆盖旧快照、进程缓存及进程重启后的恢复，验证容量更新且原模型不变；Swift 覆盖旧容量及无容量字段的旧检查点，验证原运行标识和历史保留并正常完成。Host 163 项测试、Swift 65 项 XCTest 及 13 项 Swift Testing 均通过。

## 恢复后的旧验收阻塞

安装 `79d0df587` 后，通过界面重试原运行。Host 从版本 6、迭代 2 前进到版本 15、迭代 5，Run 和 Turn 均成功，实际完成 `todo_get_context` 和 `todo_acceptance_update`，验收 3 持久化为 passed，无上述配置及摘要错误。

但验收 4 仍保留恢复前的 Human 阻塞状态。验收 3 更新后，统一验收门判断只剩 Human 阻塞，自动结束本轮；模型没有机会重新核验旧阻塞。这是 Todo 重开时只恢复任务状态、未恢复验收状态造成的。

现在所有普通重开及 Human 明确重试共用的事务，在 blocked → pending 时将旧 blocked 验收项恢复为 pending，并保留已有证据和通过项；原阻塞诊断仍保存在进度记录。执行者必须按当前输入重新核验，真实阻塞仍可再次明确登记，不能直接标记通过。真实 SQLite 回归覆盖两种重开入口，以及更新一项后其余旧阻塞仍可继续处理；相关任务工具、存储、调度和原生执行器共 125 项测试通过。
