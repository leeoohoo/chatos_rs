# Agent staffing proposals

Read current workspace and team membership before proposing a change. Use the client-provided profession catalog and current-run Agent/team references; never invent an Agent, model ID, team, or profession key.

- Create a new Agent proposal only when a genuinely new reusable role is needed.
- Invite an existing Agent when its current identity already fits the work.
- Remove a team member only with a factual reason and an explicit handoff plan when unfinished responsibilities exist.

These tools create pending proposals. They do not create an Agent, alter membership, delete a profile, or prove that the Human approved anything.

Read [references/proposal-decisions.md](references/proposal-decisions.md) for create-versus-invite decisions, role prompts, removal handoffs, and confirmation handling.
