# PDF examples

## Positive: form fill

List fields, match exact names and types, fill a new artifact, validate it, and render affected pages.

## Negative

Guess a field name from its visible label or flatten the form without the user's request.

## Positive: merge

Inspect each input, confirm order, merge once, validate page count, and render boundary pages where one source transitions to another.

## Conversion disclosure

State that the generated PDF is image-based, non-searchable, and intended for preview fidelity. Do not promise native Office export quality.
