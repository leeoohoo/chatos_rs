# Presentation examples

## Positive

Create a short narrative: problem, evidence, approach, architecture, rollout, and decision. Give each slide one purpose, then validate and render all slides for visual review.

## Negative

Put every fact into one slide with tiny text, or report that a deck looks correct without rendering it.

## Focused revision

Inspect the source, change only the requested slides, preserve the remaining order and styling, render changed slides, and return a new artifact.
