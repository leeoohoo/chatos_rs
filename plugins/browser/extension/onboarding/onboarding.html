让 Chatos 使用你的 Google Chrome

只需在每台电脑、每个 Chrome 用户配置中授权一次。之后任务会自动连接，并把新页面放进任务标签组。

在 Chatos 发起浏览器任务

Browser MCP 会在本机启动安全 Bridge，不会把浏览器控制端口暴露到公网。

2

连接并授权本机

点击下方按钮完成一次性授权。其他用户仍需在自己的电脑上分别授权。

3

返回 Chatos

连接成功后，新建页面会自动进入以任务名称命名的 Chrome 标签组。

扩展只连接本机 Native Messaging Host 和 127.0.0.1 回环地址；只有任务创建的标签页和你主动共享的标签页可被控制。
