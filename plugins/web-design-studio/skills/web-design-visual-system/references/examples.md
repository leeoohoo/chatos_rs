# Visual examples

## Positive

A developer tool site uses a dark neutral base, one electric accent, compact mono metadata, generous editorial headings, subtle grid texture, and consistent 8/16/24/40 spacing.

## Negative

Apply several unrelated gradients, glass cards, neon shadows, and tiny body text because each effect is individually available.

## Focused revision

When the user asks to improve one section, preserve the established token system and neighboring geometry. Change only the targeted composition and any shared token explicitly needed by it.
