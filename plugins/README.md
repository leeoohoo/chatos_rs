# First-party plugins

The first-party ChatOS plugins are maintained in this repository so client protocol, permission, packaging, and release changes can be reviewed together.

- `browser/`: Rust Browser CDP MCP, launcher package, skill, and Chrome bridge extension source.
- `computer-use/`: native macOS and Windows Computer Use MCP implementations.
- `document/`: TypeScript Office and PDF MCP with workspace and artifact boundaries.

Only source, tests, manifests, lockfiles, scripts, licenses, and reproducibility metadata are tracked. Build outputs, package archives, downloaded dependencies, and vendor executables are regenerated by each plugin's build scripts. Document plugin tests fetch and checksum the current platform's OfficeCLI runtime before exercising Office mutations.
