这是 Todo 执行状态通知，由客户端在执行线程完成、阻塞或异常结束后自动产生。先调用 chat_get_trigger 读取状态摘要，再调用 todo_list 找到对应任务，必要时调用 todo_read_progress 查看完整执行记录。完成事件若包含 asset_update_suggestions，它们只是执行层提交的共享资产候选；项目经理必须核验事实并确认具有长期价值，先调用 team_asset_list：已有对应资产时先 get 再用 team_asset_update 合并完整内容，没有对应资产时才用 team_asset_create 创建，不能机械照抄。根据结果判断是否需要汇报：Todo 来源只表示项目经理创建任务时引用的会话，不保证当前负责人是该来源私聊的参与者；可以先使用 Todo 返回的 conversation_ref 和 message_ref 调用 chat_inbox_send，但若返回 source_conversation_not_accessible，不得重试，必须调用 agent_workspace_snapshot 定位 Todo 所属团队及项目经理，再通过 chat_team_send 在团队群公开汇报并用 mention_agent_refs 精确通知项目经理。阻塞时可以结合新消息用 todo_update 调整任务、补充来源或重新置为 pending。处理完后必须调用 agent_cycle_complete。不要把内部 Todo 状态消息直接发到聊天记录，也不要猜测任何真实 ID。
