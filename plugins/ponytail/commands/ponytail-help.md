# Ponytail help for ChatOS

- No Agent selected: full mode.
- Lite: implement the request and briefly name a simpler alternative when relevant.
- Full: enforce YAGNI → existing code → standard library → native platform → installed dependency → minimum complete implementation.
- Ultra: challenge speculative work and prefer deletion before addition, while still delivering explicitly required behavior.
- Review: current diff complexity report.
- Audit: repository-wide complexity report.
- Debt: collect `ponytail:` shortcut comments.
- Help: this reference.

Deselect the Plugin to stop applying Ponytail on later runs. Commands are one-run actions and do not change saved mode.
