# Validation and export

Run `web_design_validate` after multi-component work and before reporting completion. Repair blocking structure, page ownership, parent cycles, overflow, and layout issues. For a new or substantially redesigned page, inspect desktop, tablet, and mobile.

Verify queued requests are resolved only after their visual changes exist. Verify interactions by previewing the destination or HTTPS target when relevant. On revision conflict, reread and rebase rather than replacing user work.

Export HTML, React, or Vue only when the user asks for code. Return managed artifacts from the export result and state what was generated. An export does not replace design validation.

Read [validation examples](references/examples.md) before declaring a large design complete.
