首次安装引导

  1. 安装插件：在 ChatOS 插件市场安装并启用 Browser CDP。
  2. 授权能力：为插件开启“连接现有 Chrome”权限。
  3. 启动任务：在 ChatOS 中运行一个会使用 Browser CDP 的任务。
  4. 完成配对：回到这里点击“首次连接”。成功一次后，MCP 或扩展重启会自动恢复连接。

任务创建的页面会自动进入以任务名称命名的 Chrome 标签组；任务结束后标签保留并折叠。

连接不上怎么办？
  • 确认 ChatOS 和 Local Connector 正在运行。
  • 先启动一个 Browser CDP 任务，再点击“首次连接”。
  • 插件升级后无需重新配对；若主动点过“断开连接”，需要再次点击“首次连接”。
