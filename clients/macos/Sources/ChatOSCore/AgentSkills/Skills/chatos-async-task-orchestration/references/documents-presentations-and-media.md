# Documents, presentations, and media

Plan artifact work around source preparation, production, and format-specific verification.

For documents/PDFs specify editable and delivery formats, sections/pages, templates, styles, citations, tables/forms, and accessibility. Require render-based visual QA when layout matters. For spreadsheets state sheets, tables, formulas, inputs/outputs, validation, charts, and recalculation; prefer one workbook writer.

For presentations define audience, duration, narrative, slide range, notes, visual system, and citations. Research and visual direction may run in parallel; deck assembly owns the final file and a later Task verifies content and rendered slides.

For image, audio, and video specify ratio, duration, resolution, codec/format, editable project, source rights, captions/transcript, variants, and delivery location. Script, assets, production, and QA often merit separate Tasks. Acceptance requires a usable artifact verified by opening, rendering, playback, or format inspection, not just a text description.
