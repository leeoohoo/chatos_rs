# Focus examples

## Positive

Activate the known bundle, verify its title and visible window, click the intended editor, verify focus, then type.

## Negative

Send Command+S because the requested app was active several screenshots ago. Another application or dialog may now own the keyboard.

If typing appears in the wrong place, stop. Observe the full display, identify the actual foreground app and modal state, then reacquire the intended field instead of sending compensating shortcuts blindly.
