# chatos-compact-communication

Product-owned communication policy for local ChatOS Agents.

- Version: 2
- Manager content: `SKILL.zh-CN.md` / `SKILL.en.md`
- Executor subset: `EXECUTOR.zh-CN.md` / `EXECUTOR.en.md`
- The client records the selected language, audience, version and content SHA-256 in the Run checkpoint.
